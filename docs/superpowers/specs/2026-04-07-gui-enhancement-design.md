# SemSub GUI Enhancement Design

## 概述

将SemSub的GUI功能完善至与CLI对标，提供完整的字幕生成、工作区管理、阶段执行和配置管理功能。

**设计目标：**
- 功能完整对标CLI（6个命令的所有功能）
- 侧边栏导航的模块化布局
- 统一批量界面，单文件时显示工作区详情
- 双区域布局的工作区面板（左：流程图，右：详情）

---

## 一、整体架构

### 1.1 导航结构

采用**侧边栏导航**布局，左侧固定导航栏包含4个模块：

| 模块 | 功能范围 | 对标CLI命令 |
|------|----------|-------------|
| 字幕生成 | 批量处理、配置、进度 | `semsub generate` |
| 工作区状态 | 查看状态、artifacts、统计 | `semsub status` |
| 阶段执行 | 单阶段运行、强制重执行、断点续传 | `semsub run-stage` |
| 配置管理 | 配置向导、导入导出、预设管理 | `semsub config` |

### 1.2 窗口布局

```
+------------------+------------------------------------------+
|                  |                                          |
|   侧边栏导航      |               主内容区域                   |
|                  |                                          |
|  [字幕生成]       |   [根据选中模块变化的动态内容]              |
|  [工作区状态]     |                                          |
|  [阶段执行]       |                                          |
|  [配置管理]       |                                          |
|                  |                                          |
+------------------+------------------------------------------+
```

### 1.3 视觉风格

- **主题**：深色主题（适配视频处理场景），主色调蓝色
- **图标**：使用Phosphor Icons风格图标
- **字体**：系统默认中文字体 + 等宽字体用于日志
- **动画**：阶段状态切换平滑过渡，进度条流畅更新

## 二、模块详细设计

### 2.1 字幕生成模块

**对标CLI：** `semsub generate`

#### 布局结构

```
+-------------------------------------------------------------+
|  文件选择区域： [添加文件] [添加目录] 已选择 X 个文件           |
+-------------------------------------------------------------+
|                         |                                   |
|   文件列表              |     双面板配置区                  |
|   +----------------+    |     +------------------------+    |
|   | video1.mp4  ✓  |    |     | 快速选项                |    |
|   | video2.mp4  ⏳  |    |     | - Preset: [电影 ▼]      |    |
|   | video3.mp4  ✗  |    |     | - 语言: [自动检测 ▼]     |    |
|   +----------------+    |     | - 格式: [SRT ▼]         |    |
|                         |     | - 从 [开始] 到 [结束]    |    |
|   (支持拖拽添加)         |     +------------------------+    |
|                         |     | 高级选项 [展开 ▼]        |    |
|                         |     +------------------------+    |
|                         |                                   |
+-------------------------+-----------------------------------+
|  整体进度: [████████░░░░░░░░░░] 40% (2/5)                    |
|  当前视频: [████████████████░░] 80% - video2.mp4             |
|  统计: 已完成 1 | 处理中 1 | 待处理 2 | 失败 1                |
+-------------------------+-----------------------------------+
|  日志输出                                                   |
|  [14:32:01] 开始处理 video2.mp4...                           |
|  [14:32:05] 音频提取完成                                     |
+-------------------------------------------------------------+
```

#### 快速选项面板

| 选项 | 类型 | 说明 |
|------|------|------|
| 预设场景 | 下拉选择 | movie / documentary / animation |
| 语言 | 下拉选择 | 自动检测 / Chinese / English / Japanese |
| 输出格式 | 下拉选择 | srt / vtt / json |
| 阶段范围 | 双下拉选择 | 从 X 阶段 到 Y 阶段（可选） |

#### 高级选项折叠区

展开后显示：
- **VAD设置**：阈值滑块、最小语音时长、最小静音时长
- **字幕设置**：最大字符数、最大显示时长、最小显示时长、合并阈值
- **LLM设置**：启用开关、Base URL、API Key、模型、输出模式
- **处理选项**：
  - ☑️ 跳过已存在字幕的视频 (--skip-existing)
  - ☑️ 遇到错误继续处理 (--continue-on-error)
  - ☑️ 强制重新执行 (--force)

#### 文件列表交互

- 选中**单个文件** → 右侧面板切换为**工作区面板**（显示该文件的阶段流程图）
- 选中**多个/无选中** → 右侧面板显示批量配置面板
- 支持多选、拖拽排序、右键菜单（移除、打开文件夹）

#### 工作区面板组件

**阶段流程图（StageFlowWidget）：**
- 水平排列5个阶段卡片
- 卡片颜色编码：
  - 灰色：等待
  - 蓝色：运行中
  - 绿色：已完成
  - 红色：失败
- 卡片间用箭头连接
- 点击卡片选中该阶段

**阶段详情面板：**
- 基本信息：阶段名称、状态、开始/结束时间、耗时
- Artifacts列表（当开启--artifacts时）：
  - 文件名、大小
  - 关键统计信息（如片段数、字幕行数等）
- 操作按钮：查看输入文件、查看输出文件

### 2.3 阶段执行模块

**对标CLI：** `semsub run-stage [--force] [--resume]`

#### 布局结构

```
+-------------------------------------------------------------+
|  视频选择列表        |   阶段执行面板                        |
|                     |   +------------------------------+    |
|  [video1.mp4]       |   | 目标阶段选择                   |    |
|  [video2.mp4] ◄─────┼───┼  [01_音频提取 ▼]               |    |
|  [video3.mp4]       |   +------------------------------+    |
|                     |   | 依赖关系图                     |    |
|                     |   |  ✓ 01_音频提取 [已完成]        |    |
|                     |   |  ✓ 02_VAD分割  [已完成]        |    |
|                     |   |  ▶ 03_ASR转录  [待执行] ◄──目标 |    |
|                     |   |  ○ 04_字幕优化 [依赖]          |    |
|                     |   |  ○ 05_LLM处理  [依赖]          |    |
|                     |   +------------------------------+    |
|                     |   | 执行选项                       |    |
|                     |   | ☑️ 强制重新执行 (--force)       |    |
|                     |   | ☑️ 从检查点恢复 (--resume)      |    |
|                     |   +------------------------------+    |
|                     |   | [执行阶段] [查看输入] [查看输出] |    |
|                     |   +------------------------------+    |
+-------------------------------------------------------------+
```

#### 交互流程

1. 用户从左侧选择视频
2. 从下拉框选择目标阶段
3. 系统检查依赖关系并可视化显示
4. 如果依赖未完成：
   - 显示警告提示
   - 提供"先执行依赖"按钮
   - 或勾选"强制执行"跳过依赖检查
5. 点击"执行阶段"弹出进度对话框
6. 执行完成后刷新状态

### 2.4 配置管理模块

**对标CLI：** `semsub config [show|set|get|list-presets|export|import|wizard]`

#### 标签页结构

```
+-------------------------------------------------------------+
|  [配置向导] [当前配置] [预设管理] [导入导出]                   |
+-------------------------------------------------------------+
|                                                             |
|  (根据选中标签显示不同内容)                                   |
|                                                             |
+-------------------------------------------------------------+
```

#### 配置向导标签

4步向导，带步骤指示器：

**步骤1：LLM配置**
- 启用LLM后处理 开关
- Base URL 输入框
- API Key 密码输入框
- 模型名称 输入框
- 输出模式 下拉选择（correct/translate/bilingual）

**步骤2：字幕配置**
- 最大字符数（中文/英文）
- 最大/最小显示时长
- 合并阈值
- 预设快速选择按钮

**步骤3：ASR配置**
- 批次大小
- 语言选择
- 模型路径

**步骤4：保存配置**
- 保存位置选择：用户配置 / 项目配置
- 配置预览
- 保存按钮

#### 当前配置标签

树形结构显示合并后的配置：
```
▶ vad
  ├─ threshold: 0.5
  ├─ min_speech_duration_ms: 250
  └─ min_silence_duration_ms: 500
▶ subtitle
  ├─ max_chars: 40
  └─ ...
▶ asr
▶ llm
▶ output
```

支持双击编辑值，保存时验证类型。

#### 预设管理标签

- 预设列表（movie/documentary/animation）
- 选中预设显示详细参数预览
- 操作按钮：应用此预设、导出预设、复制为新预设

#### 导入导出标签

- 导入配置：文件选择器 + 导入位置选择（用户/项目）
- 导出配置：文件保存对话框
- 拖放支持：直接拖入配置文件进行导入

```python
class StageWorker(QThread):
    started = pyqtSignal(str)           # stage_id
    progress = pyqtSignal(int, str)     # percent, message
    finished = pyqtSignal(bool, str)    # success, message
    error = pyqtSignal(str)
    log = pyqtSignal(str)
```

## 四、数据流设计

### 4.1 字幕生成流程

```
用户点击"开始生成"
    ↓
收集所有配置参数
    ↓
创建 BatchWorker 线程
    ↓
对每个视频：
    - 创建/打开 Workspace
    - 根据阶段范围确定起始阶段
    - 执行 pipeline
    - 发送进度信号
    ↓
完成所有视频后更新状态
```

### 4.2 阶段执行流程

```
用户选择视频和目标阶段
    ↓
检查依赖关系
    ↓
创建 StageWorker 线程
    ↓
执行目标阶段（使用 StageExecutor）
    ↓
发送实时进度信号
    ↓
完成后刷新工作区状态
```

## 五、错误处理

| 场景 | 处理方式 |
|------|----------|
| 依赖未满足 | 显示警告，提供"先执行依赖"按钮 |
| 工作区被锁定 | 提示其他进程正在使用，提供强制解锁选项 |
| 阶段执行失败 | 显示错误详情，提供查看日志按钮 |
| 取消操作 | 设置取消标志，等待当前阶段完成后停止 |
| 配置验证失败 | 高亮错误字段，显示具体错误信息 |
